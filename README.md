# azizfaraj.github.io

Personal academic website of Abdulaziz Alfaraj, live at <https://azizfaraj.github.io>.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Where things are

| To change | Edit |
|---|---|
| Name, sidebar bio, links, email | `_config.yml` (the `author:` section) |
| Header menu | `_data/navigation.yml` |
| Home page | `_pages/about.md` |
| CV page | `_pages/cv.md` |
| Papers | one file per paper in `_publications/` |
| Profile photo | `images/profile.jpg` |
| PDFs (CV, papers) | `files/` (served at `/files/<name>.pdf`) |
| Color theme | `site_theme` in `_config.yml` (`default`, `air`, `sunrise`, `mint`, `dirt`, `contrast`) |

Pushing to the `main` branch rebuilds the site automatically on GitHub Pages.
